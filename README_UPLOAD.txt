CARBON ATLAS — GITHUB WEB UPLOAD EDITION

This package is intentionally small so GitHub's browser uploader can accept it.

UPLOAD:
1. Open the GitHub folder that currently contains your website index.html.
2. Choose Add file > Upload files.
3. Upload ONLY index.html from this folder.
4. Commit the change.
5. Wait for GitHub Pages deployment, then hard-refresh the site.

WHAT IS INCLUDED INSIDE index.html:
- Complete dark Carbon Atlas UI
- World map geometry
- All seven interactive colour 3D models
- Camera-view placement
- WebXR floor AR when supported by the browser/device
- Ecosystem descriptions, Learn More sections, filters, and monitoring details

WHAT WAS REMOVED:
- Redundant standalone GLB/USDZ export files. Those files caused the previous upload bundle to total about 71 MB. The in-page 3D models do not need them.

IMPORTANT:
Do not upload the old GLB/USDZ files with this edition. The website will work without them.
